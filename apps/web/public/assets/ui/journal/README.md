# Journal artwork

Generated for Realm of Shadows in the flat glossy cartoon style, referencing the existing purple/silver player menu. Both PNGs have real alpha transparency and are retained unchanged. Lossless delivery copies are mapped by `optimized-manifest.json`.

- `icons.png`: journal, quest, combat, gold, completion, lock, compass, quill, purple/gold action ribbons, back arrow, close icon. The generated sheet contains no text; accessible labels stay in HTML.
- `icons.json`: isolated display rectangles for the generated icons. SVG clips prevent adjacent sprites appearing in controls; artwork keeps its original proportions.
- `hero.png`: open purple travel journal with a quill and a route through Woods, Crystal, Murkmire and Frostfall emblems. No story spoilers or invented characters.

Original generation outputs: `exec-2147fb94-0605-4925-8615-a071faf697e0.png` and `exec-4bb11011-3499-4c53-a71e-504edcefdff4.png`.

Quest-giver portraits, monsters, equipment and resource rewards use the existing in-game atlases. Only the selected quest's NPC and enemy sheets load; atlas metadata is cached between selections.
