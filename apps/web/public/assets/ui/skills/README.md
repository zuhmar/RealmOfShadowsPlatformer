# Skills artwork

`icons.png` is a generated transparent atlas, matching the existing purple/silver glossy journal artwork. The original 1254 × 1254 PNG is unchanged. `icons.json` isolates each of the sixteen icons for clipped, proportional UI display.

Subjects: melee, magic, distance, mining, woodcutting, fishing, herbalism, blacksmithing, carpentry, cooking, alchemy, critical hits, dodge, shield, health, and mana. All text and values are accessible HTML. Buttons reuse the generated purple/gold journal ribbons; the header uses the player's actual equipped skin sprite.

Original generation output: `exec-f08a9424-2b63-4cd9-bbeb-e453f8c25a71.png`. Delivery encoding preserves dimensions and exact alpha; the source is retained.
