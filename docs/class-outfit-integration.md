# Celestial class outfit integration

Knight, Archer, Mage and Rogue now use their approved normal-colorway Celestial outfits in the live renderer. White featureless exposed faces/hands retain the character identity; clothing has its own steel/blue, green/brown, blue/silver or charcoal/burgundy palette. NPC outfits and creature artwork are unchanged. No hidden-origin appearance is offered.

## Selection and saves

Claim the Crystal Caverns class trial and choose a class. The matching outfit equips automatically. **Character → Change skin** offers the bare Celestial form and four class outfits; only the matching class outfit can be worn. Switching appearance is free and does not alter equipment, attributes, training or class. Server validation rejects other classes’ outfits and unknown IDs.

On first entry with the new concept version, existing class characters adopt their matching outfit and civilians stay Celestial. `skinConceptVersion: 2` records this one-time migration. Later explicit choices of the bare Celestial or class outfit are preserved through travel/re-entry. Invalid saved class outfits normalize to the matching class or Celestial for civilians. Class changes continue to require the existing quest, location and gold checks and select the newly chosen class outfit. No schema migration is needed.

## Weapons and animation

`classSkinSheet` in game-data selects by equipped weapon, not by the current map. The bare Celestial body also selects baked starter/Woods/Crystal sheets for all four weapon types via `baseSkinSheet`. Each class has an unarmed sheet, a starter armed sheet and two active-island armed sheets (`-armed-woods`, `-armed-crystal`). Woods art matches the Ironwood equipment designs; Crystal art matches cyan crystal/purple gem equipment designs. Rogue holds two matching daggers visually while using the existing single weapon equipment slot and existing damage rules.

Climbing, gathering and actual unarmed states use the unarmed class sheet. Gathering tools still follow the server-selected equipped tool, including automatic wooden starters. Armed sheets have baked weapons; extra weapon overlays are hidden. If an armed texture is still loading, the renderer uses the unarmed class body or bare Celestial fallback with a matching weapon overlay until it arrives. Unsupported later-island weapons also use this overlay path rather than displaying an incorrect baked starter weapon.

Basic attacks use `attack`; skill timestamp changes use `skill` where available. Idle/walk/climb loop, attacks and deaths finish once, and jump poses follow the existing velocity mapping. No hurt animation. Sheet changes preserve source proportions and foot-aligned trim geometry. Only the visible character’s class/body/equipped variant is requested; textures and metadata are shared by characters using the same sheet.

## Art and verification

There are 16 class sheets / 576 authored frames under `apps/web/public/assets/characters/skins/celestial`. `manifest.json` records tier, source originals, class, weapon and clips. The eight new island sheets were generated by editing only weapons in the approved armed sheets using the island equipment atlas as reference. Original PNG bytes are retained; metadata bounds frames without repainting. Delivery WebP copies preserve dimensions and exact alpha.

Checks: `npm test`, `npm run typecheck`, `npm run build`, `npm run test:integration`, `node scripts/browser-celestial-sheets.mjs`, `node scripts/browser-skin-rendering.mjs`, and `node --env-file-if-exists=apps/server/.env --import tsx scripts/browser-class-skins.mjs`. Coverage includes migration, allowed appearances, weapon tier selection, all clips/frames, live weapon switching, tools, unarmed ladders, class quest carousel and saved skin re-entry.
